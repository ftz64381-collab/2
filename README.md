# إعداد تسجيل الدخول بواسطة ديسكورد لمنصة Render

## الخطوات الأساسية:
1. **بوابة المطورين (Discord Developer Portal):**
   - ادخل على حساب البوت الخاص بك.
   - اذهب إلى قسم **OAuth2**.
   - في خانة `Redirects`، أضف الرابط التالي:
     `https://<اسم-موقعك-في-رندر>.onrender.com/callback`
   - انسخ الـ `CLIENT_ID` و `CLIENT_SECRET` وضعهم في ملف `config.json`.

2. **منصة Render:**
   - السكريبت الآن مجهز لسحب المنفذ (PORT) تلقائياً من بيئة Render بدون تدخل منك.
   - تأكد أن أمر التشغيل (Start Command) في Render هو:
     `python main.py`

3. **الواجهة الأمامية (React & Vite):**
   - الكود الحالي يقدم واجهة HTML مدمجة تفي بالغرض مباشرة وتم إخفاء الآيدي فيها لمنع التزوير.
   - إذا رغبت مستقبلاً بفصلها لمشروع React (Vite + Tailwind) كما هو واضح في ملف الـ package الخاص بك، يمكنك تحويل الردود في الـ `/callback` إلى `JSON` واستقبالها في React عبر الـ `fetch`.
